# JOKINJAY Project Knowledge Base

## Ecosystem Status
- **Website (LIVE)**: `https://jokinjay.vercel.app`
- **Mobile (DEV)**: Flutter App (Android/iOS) - Syncing UI.
- **Repository**: `https://github.com/Rapprince29/JOKINJAY.git`

## Feature Map
### Web Platform (Frontend)
- **UI**: Cyber Minimalism Bento Grid + GSAP.
- **Auth**: NextAuth (Google Login configured).
- **PWA**: Manifest & Service Worker aktif (Installable).
- **Pricing**: Dynamic calculation based on category & deadline.

### Mobile Platform (Mobile-Apps)
- **Framework**: Flutter.
- **UI**: Cyber Theme (Inverted Logo support).
- **Branding**: Official `logo.jpeg` as App Icon & Splash Screen.
- **Auth**: Firebase Integration (IN_PROGRESS).

## Important File Paths
- **Web Root**: `frontend/src/app/`
- **Mobile Root**: `mobile-apps/lib/`
- **Global Assets**: `frontend/public/` (Source of truth for logos).
