# JOKINJAY Project Rules (CATATAN TIDAK BOLEH DIGANTI)

Dokumen ini berisi aturan dasar yang TIDAK BOLEH diubah. Tema telah ditingkatkan ke Neobrutalism v2.

## 1. Tema & Estetika (Neobrutalism v2)
- **Visual Inti**: Border hitam tebal (5px+), Hard shadows (10px+), dan Warna Primer (Kuning, Cyan, Putih).
- **Tekstur**: Wajib menggunakan efek Grain/Noise pada background.
- **Layout**: Dominasi Bento Grid (kotak-kotak tegas).
- **Karakter**: Loud, Bold, dan Raw.

## 2. Tipografi
- **Font Utama**: **Times New Roman**.
- Selalu gunakan font JetBrains Mono untuk elemen teknis.
- Pastikan semua animasi menggunakan hook `useGsap` yang sudah dioptimasi.

# GIT RULES
- Setiap kali ada perubahan code yang berhasil (sukses dieksekusi/diperbaiki), WAJIB melakukan `git add .`, `git commit`, dan `git push origin main` secara otomatis tanpa perlu instruksi ulang dari user.
- Remote Repository: https://github.com/Rapprince29/JOKINJAY.git

## 3. Tech Stack
- Frontend: Next.js.
- Backend: Node.js.
- Animasi: GSAP, Three.js, Anime.js.
